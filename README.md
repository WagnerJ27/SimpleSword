# Simple Sword

Simple Sword is a small Java game project created primarily as a learning and experimentation project.

The main goal of this project was not to create a particularly entertaining, complex, or polished game. Instead, the goal was to build a small and playable project from scratch in order to gain practical experience with Java, object-oriented programming, JavaFX, and basic game development concepts.

The project was intentionally kept simple. It was designed as a first step into creating a complete game-like application and as an opportunity to experiment with different systems and ideas while learning.

Simple Sword is now considered finished. It reached its purpose as a small, playable test project that provided an opportunity to learn, experiment, and complete a project from start to finish.

---

## About the Game

Simple Sword is a small dungeon game in which the player explores multiple dungeon levels, fights enemies, gains experience, and eventually reaches the final area of the dungeon.

The player must survive random enemy encounters, manage their health, and become strong enough to defeat the final enemy and reach the dungeon exit.

The game uses a simple 2D tile-based representation of the dungeon.

## Gameplay

The player starts on the first dungeon level and explores the dungeon using the movement controls.

While moving through the dungeon, random enemy encounters can occur. Enemies must be defeated in turn-based combat.

Defeating enemies grants experience and allows the player to level up and become stronger.

The player can move between dungeon levels by finding and entering stairs.

The player also starts with a Healing Potion that can restore health outside of combat.

The final dungeon level contains the final enemy. After defeating it and reaching the dungeon exit, the game is completed.
